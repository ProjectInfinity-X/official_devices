Infinity v4.2 (Android 17)

Device Changelog 22/11/2026:

Base

-Update to OS3.0.304.0.WNRMIXM: new fingerprints, vendor security patch 2026-10-01, and the updated camera and video firmware, GPU zap shader, camera.qcom, chi.override, PAL, mialgoengine and MipayService blobs. (author: Alhaidar Latif)
-Shim the fingerprint and QSEECom blobs with libion_shim, so they close their ion fds and qseecom_region no longer runs out of memory. (author: AdarshGrewal)
-Drop the legacy libion implementation, the shim covers it now. (author: bezke)
-Declare Vulkan 1.3 support for the Adreno V837.0.9 drivers. (author: Alhaidar Latif)
-Drop the AVB GSI keys from the fstab and vendor_boot. (authors: Mashopy, Sigmund05)
-fastbootd is now enabled by default, drop the device flag. (author: Nolen Johnson)

Kernel

-Move the kernel to the LineageOS lineage-24.0 base. (author: bezke)
-Import KernelSU-Next from the dev-susfs branch. (author: Omar Mohamed)
-Implement SUSFS v2.3.0 and fix rebooting with SUSFS included. (author: Omar Mohamed)
-Rewire the SUSFS SELinux hooks to the KernelSU-Next exports and sync the exec and reboot hooks with the dev-susfs port, so context, access, setprocattr and status page spoofing work again. (author: bezke)
-Import NoMount v2.2.0 as built-in. (author: bezke)

Audio / Media

-Delay the audio HAL until the smart PA type property is set, which fixes missing sound on the first boot after a clean flash. (author: Alhaidar Latif)

Charging

-Let batterysecret swap the typec data role, so charger authentication no longer fails. (author: Joey)

Note for updaters

-Recommended firmware: OS3.0.304.0 (HyperOS 3, Android 16).
-Root is built into the kernel (KernelSU-Next with SUSFS). Use a KernelSU-Next manager that matches the dev-susfs kernel side, otherwise it reports "manager too low".
-NoMount users: the kernel side is v2.2.0, install the matching v2.2.0 module.
