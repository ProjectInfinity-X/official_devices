Date - 30/07/2026

!!! This is the first Fenrir build. **Do not update via OTA.** OTA is not supported for this release. You must manually flash both `boot.img` and `vendor_boot.img` before booting the ROM.

boot.img:
https://sourceforge.net/projects/bezke/files/klee-fenrir/boot.img/download

vendor_boot.img:
https://sourceforge.net/projects/bezke/files/klee-fenrir/vendor_boot.img/download

Installation instructions:

1. Reboot into the bootloader:
   adb reboot bootloader

2. Flash `vendor_boot.img`:
   fastboot flash vendor_boot /path/to/vendor_boot.img

3. Flash `boot.img`:
   fastboot flash boot /path/to/boot.img

4. Reboot the device:
   fastboot reboot

5. As soon as the device starts rebooting, immediately hold the **Volume Up** button to enter recovery.

6. In recovery, select:
   Factory Reset → Format Data

7. Then select:
   Apply Update → Apply from ADB

8. Sideload the ROM:
   adb sideload /path/to/lineage-23.3-xxxxxxxx-UNOFFICIAL-klee.zip
