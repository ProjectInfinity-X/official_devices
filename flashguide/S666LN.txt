Device: Itel RS4 (S666LN)
Recommended Recovery: https://t.me/itelrs4updates/164
IMG Files: https://sourceforge.net/projects/infinity-x/files/S666LN/16/img

Flashing Instructions:

Note: Due to many changes in HALs and the changelog, a clean flash is strongly recommended when updating from 3.7 to 3.8. Sorry for the inconvenience.

* Clean Flash:
- Wipe Dalvik, ART & Cache, Metadata, Data
- Format Data
- Flash ROM
- Format data
- Reboot
- Install ofox
- Reboot Recovery
- Install nikgapps core (if youre using vanilla)
- Reboot

* Dirty Flash: 
- Reboot to recovery
- Flash ROM.zip (Reflash gapps if youre using vanilla version)
- Wipe Cache, Dalvik
- Reboot
