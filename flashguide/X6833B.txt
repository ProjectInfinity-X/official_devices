Recommended Recovery: Infinity X recovery. Can be found [HERE](https://sourceforge.net/projects/infinity-x/files/X6833B/17/vendor_boot_X6833B.img/download)

1.Reboot your device into fastboot

2. Connect device via USB and flash vendor_boot to both slots:

fastboot flash vendor_boot_a vendor_boot_X6833B.img
fastboot flash vendor_boot_b vendor_boot_X6833B.img

3.Reboot to recovery, then in recovery select Apply update > Apply from ADB > ADB sideload

Flashing Instructions:
Clean Flash
Tap Factory reset > Format data/factory reset > Format data
Format cache partition
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)
Reboot

Dirty Flash
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)

Reboot

OTA Update
Simply upgrade via OTA updater
