Recommended Recovery: Infinity X recovery. Can be found [HERE](https://sourceforge.net/projects/infinity-x/files/agate/17/boot.img/download)

0.Make sure you are on a MIUI 14 based rom (You cannot flash from HyperOS)

1.Reboot your device into fastboot

2.Connect device via USB and run:

fastboot flash boot boot_agate.img

Flashing Instructions:
Clean Flash
Tap Factory reset > Format data/factory reset > Format data
Format cache partition
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)
Reboot

Dirty Flash
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)

Reboot

OTA Update
Simply upgrade via OTA updater
