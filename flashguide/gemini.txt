Recommended Recovery: Infinity X recovery. Can be found in the Retrofit Kit

Mandatory Pre-requisite: Download the Retrofit Kit, extract it, and run flash_retrofit.bat (or .sh) while in fastboot mode. The device will automatically boot into recovery. In the Recovery You Need To Format Data

If The Recovery does not boot try booting again with: fastboot boot recovery.img

Flashing Instructions:

Clean Flash

Tap Factory reset > Format data/factory reset > Format data

Format cache partition > Format system partition

Sideload Firmware (https://codeberg.org/rewoaP/Gemini/src/branch/main/FW_Gemini_MIUI_GEMINI_Global_8.11.22_8.0.zip)

Sideload Infinity-X ROM zip via recovery (adb sideload .zip)

Reboot (Note: First boot takes ~15-17 minutes, do not interrupt)

Dirty Flash

Sideload Infinity-X ROM zip via recovery (adb sideload .zip)

Reboot
