Recommended Recovery: Infinity X recovery. Can be found [HERE](https://sourceforge.net/projects/infinity-x/files/a53x/17/recovery.img/download)

1.Reboot your device into download mode

2.Connect device via USB and open Odin and flash disable vbmeta by flashing this to BL slot
https://t.me/Exy1280_dis/313925

3.Tar the recovery image by using tar -H ustar -c recovery.img > recovery.tar

4.Flash recovery to AP slot 

5.Reboot to recovery, then in recovery select Apply update > Apply from ADB > ADB sideload

Flashing Instructions:
Clean Flash
Tap Factory reset > Format data/factory reset > Format data
Format cache partition
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)
Reboot

Dirty Flash
Sideload Infinity-X ROM zip via recovery (adb sideload <filename>.zip)

Reboot
